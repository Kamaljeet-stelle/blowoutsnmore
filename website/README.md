# Blowouts N' More — Website Prototype

Premium responsive salon website built with React, TypeScript, Vite, Tailwind CSS and React Router.

## Scripts

```bash
cd website
npm install
npm run dev
npm run build
npm run preview
```

## Included pages

- Home
- Services (+ filters/search)
- Service details
- Multi-step booking → WhatsApp request
- About
- Team
- Gallery (+ lightbox)
- Contact (+ FAQ)
- Privacy / Terms
